# data/cases/ — 算例真值库（当前为空，附偏差说明）

M1 DoD 要求本目录 ≥15 例、逐例有「书名 + 版次 + 例题号」。**本目录现在没有任何算例**，
原因与处置如下，不靠编造来源凑数。

## 为什么是空的

1. 口径 D07/K7：无来源（书名+版次+例题号）的数值不得作为真值。手上没有可核对的教材或手册文本。
2. 本轮选定的来源路线是「GB 50017-2017 条文说明中的官方算例」。查证结果（plan/07 §二.3、§四 V1/V2）：
   可直连渠道**只渲染表标题与条号骨架，公式式体与表体数值一律为空**，条文说明里也没有取到
   可直接录入的完整算例数值。
3. 更糟的是：查证子代理把下载的原文页缓存（原 `.tmp_verify/`，95 份 HTML/文本）**删除**了，
   而 plan/07 §一 记录的渠道 URL 当前复取返回 404（见 data/README.md 的渠道可用性一节）。
   也就是说，现在既没有数值、也没有可复核的本地证据。

结论：真值算例的数量目前只能是 0，通过率的分母为 0。这属于 plan/05 §六「算例通过率」
门槛的**前置阻塞**，不是引擎缺陷。

## 现在的替代物

`data/selfcheck/` 放引擎自校验样例（单位一致性、单调性、极限情形断言），
按 D10 明确**不参与通过率分母**，只保证引擎在数值口径上不出格。

## 解除阻塞需要什么（M2 前置）

| 通道 | 需要拿到什么 | 落到哪 |
|---|---|---|
| 正式文本（纸质规范或出版社电子版） | 表 4.4.1 / 4.4.5 / 4.4.6 / 11.4.2-1 / 11.4.2-2 / 7.4.6 / 7.4.7 表体数值；式 11.2.1-1、11.2.2-1、11.4.1-1~4、11.4.2-1、7.2.1、附录 D 公式与系数 | `data/tables/`、`data/formulas/` 逐条升 verified |
| 教材/手册（可拍照或 PDF） | 例题输入 + 中间量 + 结论，逐字录入 | `data/cases/` 每条挂书名+版次+例题号 |
| 规范条文说明 | 官方算例（若确有） | 同上，来源写「GB 50017-2017 条文说明 第 X 条」 |

任何一条通道到位都能开始录入；在此之前，`sdc selfcheck` 的门控视图会持续把 5 个模块
显示为 `blocked`，这是预期行为（plan/03 §三.2）。
