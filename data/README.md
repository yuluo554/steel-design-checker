# data/ 数据台账

> 规则：每份数据登记**来源 + 许可 + status**；规范条目挂出处；程序化自制带真值的数据是核心资产
> （固定 seed 可复现，可注入已知缺陷做配对评测）。`_private/` 目录不入仓。
>
> 数据指纹口径（K12）：`data_fingerprint = sha256(data/clauses + data/tables 的规范化拼接)`，
> 规范化 = 相对路径排序 + JSON 重序列化（键排序、紧凑分隔符、UTF-8），所以排版改动不影响指纹，
> 而任一数值或条号改动必然改变指纹。算法或计入目录的变更属口径变更，需登记 plan/06。
> 实现在 `src/sdc/kb/fingerprint.py`，读取路径由 `sdc.paths.find_data_dir` 决定（K11）。

## M4（内置基准与交付物）对数据侧的影响

**`data/` 一个字节都没因 M4 改动**（指纹变化来自 M3 定档：`a39187e2…` → `235a0c14…`）。
M4 新增的是**交付物侧**的口径：docx 报告只写「标准号 + 条号 + 渠道名」，**不写渠道 URL、
不写绝对路径**（口径 K40/K42）——所以本台账与 `.tmp_verify/` 是 URL 的唯一归属地，
`tests/test_report.py` 会把任何打进正文的 `http:`/盘符路径判成外链违规并拒绝写出文件。
