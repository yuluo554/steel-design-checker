# 模拟赛题：钢结构连接与构件验算计算器（规范驱动桌面应用）

> **性质**：自拟模拟赛题（体例对标研究生大赛揭榜赛道赛题说明），与 structural-strengthening-checker 同模式：**规范公式编码（结论逐条挂条款号）+ 设计说明文本核查 + 全文强制规范检查单 + 算例真值基准**，Windows 桌面程序（PySide6 + PyInstaller exe，GitHub Release 附安装包），**零识图路线**。
> **目标产出**：GitHub 公开仓库 `steel-design-checker`。
> **题目定稿日期**：2026-10-06

---

## 一、赛题介绍

钢结构设计与复核中，**连接计算（焊缝、螺栓）是手工计算最繁琐、最易出错的部分**：焊缝有效截面换算、角焊缝正面/侧面差异化计算、螺栓群内力分配、高强螺栓摩擦面抗滑移系数取值……商业软件（PKPM/3D3S 等的钢结构模块）为闭源黑盒，教学场景与第三方复核缺乏**计算过程透明、结论可溯源到条款**的开源实现。GB 55006-2021《钢结构通用规范》作为全文强制性规范自 2022-01-01 实施后，材料选用、连接设计、构造的底线要求成为刚性合规项。

本题要求开发一款钢结构连接与构件验算计算器：首期覆盖连接计算四大高频模块与轴心受压稳定验算，公式全部编码自 GB 50017-2017《钢结构设计标准》并逐条挂条款号，配套设计说明文本核查与通用规范检查单，全离线运行、内置算例真值基准。

## 二、任务要求

### 1）连接与构件验算模块（桌面计算器核心，首期5个）

- **对接焊缝连接强度验算**（一、二、三级焊缝质量分级下的强度计算）；
- **角焊缝连接强度验算**（正面角焊缝/侧面角焊缝，含有效厚度与计算长度规则）；
- **普通螺栓连接验算**（受剪、受拉、剪拉联合）；
- **高强度螺栓摩擦型连接验算**（抗剪/抗拉，抗滑移系数与预拉力取值）；
- **轴心受压构件整体稳定验算**（截面分类、长细比、稳定系数 φ 曲线取值）。

交互：输入参数卡（钢材牌号与板厚、焊缝形式与尺寸、螺栓等级与排列、构件截面与计算长度、设计内力）→ 输出应力比与限值比、结论（满足/不满足/需调整）、**逐条依据条款号+公式编号**。纪律：公式、强度设计值、φ 曲线全部以 GB 50017-2017 原文核对后入库（status 字段），未核对条文不得进入计算路径；GB 50017-2017 强制性条文（4.3.2、4.4.1～4.4.6、18.3.3）在涉及的计算路径上强制弹出核对提示。

### 2）钢结构设计说明文本核查（规则引擎，非 CV）

- 输入：设计总说明/加工说明 docx/PDF 文本；
- 解析为"设计说明参数卡"：钢材牌号与质量等级、焊缝质量等级、螺栓性能等级、涂装与防火要求、构造措施；
- 核对：参数一致性与规范限值（焊缝等级选用、螺栓等级与构件匹配、构造要求——具体限值以 GB 50017-2017 / GB 55006-2021 原文核对后入库），异常三级判定，每条挂条款出处与原文摘录。

### 3）GB 55006-2021《钢结构通用规范》检查单

全文强制条款要点化（材料、连接、构造、防护）→ 交互式检查单逐项核对，输出符合性清单。

### 4）验算书导出

docx（输入参数、计算过程、依据条款号、结论、签署栏），带免责声明：**辅助验算工具，不替代正式设计文件与施工图审查**。

### 5）内置评测基准（零 API 依赖，含金量核心）

- **算例真值库**：钢结构教材与设计手册经典算例（数值+来源逐条登记）JSON 化入库，验算结果容差比对（目标通过率 100%）；参数扫描回归锁定（同输入必同输出）；
- **文本核查**：合成设计说明生成器（python-docx，固定 seed）植入已知错误（焊缝等级缺标注、螺栓等级与构件不符、钢材牌号前后矛盾），检出率/误报率（目标误报 0）。

## 三、提交材料

- **确定性评测优势**：连接与稳定验算是公式计算，真值=教材/手册算例，基准含金量高；

## 六、边界与非目标（防 scope 失控）

- **不做**：任何图像/点云输入；整体结构有限元分析（限构件与连接级验算）；受弯/压弯构件稳定首期不做（扩展项）；疲劳验算（扩展项）；真实工程数据（算例=教材/手册+合成说明）。
- **免责红线**：辅助验算定位，不替代正式设计与审图；报告强制免责声明。
- **条文纪律**：强度设计值表、φ 曲线、构造限值全部以规范原文核对后入库（编号+条号+渠道+status）；查不到显式标"待核对"，不得进入计算。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
