## 一、统一计算契约

```python
Result = {
  "case_id": str,
  "module": "butt_weld | fillet_weld | bolt_normal | bolt_hsb_friction | column_buckling",
  "conclusion": "satisfied | unsatisfied | need_adjust | blocked",
  "ratio": float | None,            # 应力比 / 承载力比 = 作用效应 / 抗力设计值
  "steps": [                        # 计算过程透明：逐行可核
    {"no": 1, "formula_id": "F-…", "clause_id": "GB50017-2017:…",
     "expr": "h_e = 0.7*h_f", "substituted": {"h_f": 8.0}, "value": 5.6,
     "unit": "mm", "symbol_zh": "角焊缝有效厚度"}
  ],
  "basis": [{"clause_id": …, "title": …, "kind": …, "status": "verified"}],   # 去重依据清单
  "limits": [{"param": "min_h_f", "actual": 6.0, "bound": 5.0, "op": ">=", "clause_id": …, "ok": true}],
  "warnings": [{"type": "mandatory_clause", "clause_id": "…", "message": "强条核对提示"}],
  "blocked": [{"table_id": "T-…", "clause_id": "…", "reason": "status=pending，未挂原文核对"}],
  "meta": {"engine_version": …, "data_fingerprint": "sha256(data/clauses,data/tables)"}
}
```

- `conclusion` 判定：全部 `limits` 通过且 `ratio ≤ 1.0` → `satisfied`；`ratio > 1.0` → `unsatisfied`；`ratio ∈ (0.95, 1.0]` → `need_adjust`（提示接近限值，属"需调整/宜复核"而非硬判不符合）；任一必需数据 `pending` → `blocked`（**不出数值**）。
- `data_fingerprint` 让"同输入必同输出"可被基准断言（数据变了指纹就变，回归差异可定位到数据层）。
- 容差：比值比较用相对容差 1e-3（内部计算）与真值比对的容差分开（真值容差按算例逐条登记，见 05 §四）。

## 二、验算模块参数卡（输入 schema）

公共头（所有模块）：

| 槽位 | 类型/域 | 必填 | 说明 |
|---|---|---|---|
| `case_id` | str | ✔ | |
| `module` | enum（5 值） | ✔ | 决定分派 |
| `steel_grade` | `Q235` `Q275` `Q345` `Q355` `Q390` `Q420`（+ 质量等级 A/B/C/D/E）；白名单以规范原文表核对后定稿（M1 回填，可能含 Q460/Q550 及高性能钢） | ✔ | 牌号→强度设计值查 T-steel-design-value；质量等级选用另受构造/环境条款约束（核查侧） |
| `thickness_group` | mm 分组键 | ✔ | 钢材与焊缝设计值按厚度分组，分组边界必须来自原文（待核对） |
| `weld_quality_class` | `一 | 二 | 三` | 焊缝类必填 | 对接焊缝取值差异来源；一级/二级/三级的适用范围与检验要求属核查侧规则 |
| `bolt_grade` | `4.6 | 4.8 | 5.6 | 6.8 | 8.8 | 10.9` | 螺栓类必填 | 性能等级 → 设计值/预拉力查表 |
| `forces` | `{N, V, M, T}` + 单位（kN, kN·m） | ✔ | 设计内力（荷载组合由外部给定，本项目不生成组合） |

### A1 对接焊缝 `butt_weld`

| 专有槽位 | 单位 | 说明 / 依据槽位 |
|---|---|---|
| `weld_type` | enum | 直缝 / 斜缝 / T 形对接（斜焊缝需角度 θ） |
| `has_opening_gap`（引弧板有无） | bool | 影响计算长度是否扣除弧口（§槽位：焊缝计算长度规则） |
| `groove_form` | enum | 焊透方式（全熔透/部分熔透），决定计算截面取母材还是有效截面 |
| `b`, `t` | mm | 焊缝计算宽度、被连接件较小厚度 |
| `l_w` | mm | 焊缝计算长度（有/无引弧板的规则差异） |
| 判定项 | — | 抗拉 `σ=N/A_w ≤ f_t^w`；抗压 `≤ f_c^w`；抗剪 `τ ≤ f_v^w`；法+剪共同作用式（§槽位：对接焊缝强度计算） |

计算步骤模板：截面几何（A_w、W_w、S_w、I_w）→ 应力分量 → 逐项限值比对 → 构造检查（质量等级选用与受力方向匹配）→ 结论与依据。

### A2 角焊缝 `fillet_weld`

| 专有槽位 | 单位 | 说明 / 依据槽位 |
|---|---|---|
| `h_f` | mm | 焊脚尺寸；构造最小值（与较厚件厚度相关，`1.5√t` 形式待核对）与最大值（≤ `1.2 t_min` 形式待核对）双向检查 |
| `l_w` | mm | 计算长度；须满足 `l_w ≥ max(8h_f, 40mm)`（形式待核对）与 `l_w ≤ 60h_f`（动力荷载下另有，待核对） |
| `n_welds` | int | 焊缝条数（两侧/三面围焊） |
| `load_direction` | enum | 侧面（平行焊缝长度）/ 正面（垂直）/ 混合 |
| `beta_f` | float | 正面角焊缝强度增大系数，**取值必须来自原文**（§槽位：角焊缝强度计算） |
| 判定项 | — | `σ_f = N/(h_e·l_w) ≤ β_f·f_f^w`（正面）；`τ_f ≤ f_f^w`（侧面）；同时存在正/侧面时的组合式按原文章程实现 |

`h_e = 0.7 h_f`（一般情况）作为派生步骤入 `steps[]`，其出处单独挂条号；若规范对 t 较大时 `h_e` 有附加形式，作为 `h_e_rule` 枚举分支实现，未核对不得启用。

### A3 普通螺栓 `bolt_normal`

| 专有槽位 | 单位 | 说明 / 依据槽位 |
|---|---|---|
| `bolt_type` | enum | C 级 / A、B 级（承压型），影响抗剪计算与孔径 |
| `d`, `d_0` | mm | 公称直径 / 孔径（有效截面系数 `A_e` 按螺纹处有效直径或《表》取值，待核对） |
| `group` | `{n_x, n_y, pitch, edge}` 或显式坐标列表 | 螺栓群排列；内力分配假定（形心一致、剪力度与距离成正比）挂 §槽位 |
| `bearing_parts_min_thickness` | mm | 承压计算取各方向较小 Σt |
| `load_state` | enum | 受剪 / 受拉 / 剪拉联合 |
| 判定项 | — | 单栓抗剪 `N_v^b = n_v·(π d²/4)·f_v^b`；单栓承压 `N_c^b = d·Σt·f_c^b`；单栓抗拉 `N_t^b = A_e·f_t^b`；剪拉联合 `(N_v/N_v^b)² + (N_t/N_t^b)² ≤ 1`（C 级/拉剪另有附加拉力项，按原文，待核对）；群栓最大受力栓 `N_max` 分配 |

### A4 高强度螺栓摩擦型 `bolt_hsb_friction`

| 专有槽位 | 单位 | 说明 / 依据槽位 |
|---|---|---|
| `surface_treatment` | enum | 摩擦面处理状态（喷砂/喷后涂富锌漆/手工钢丝刷等）→ μ 查表（§槽位：抗滑移系数表） |
| `slip_factor_mu` | float | 由 `surface_treatment`（+钢种）查表得到，可显式覆盖（覆盖必须来自现场试验值并记 source） |
| `preload_P` | kN | 预拉力，按性能等级 × 直径查表；有温度折减要求时挂 §槽位 |
| `n_f` | int | 传力摩擦面数目 |
| `bolt_count`, `hole_type` | — | 螺栓数、孔径（大孔/标准孔影响承载力） |
| `load_state` | enum | 受剪 / 受拉 / 剪拉联合 |
| 判定项 | — | 单栓抗剪承载力 `N_v^b = 0.9·n_f·μ·P`（系数与形式必须核对原文，§槽位）；单栓抗拉 `N_t^b = 0.8P`（形式待核对）；剪拉联合式；群栓沿受力方向的内力分配与"轴力最大栓"识别 |

**纪律提示**：本模块**只做摩擦型**；承压型高强螺栓属扩展项 E（见 02）。摩擦面处理与抗滑移系数是设计说明核查的高频缺失项（合成语料注入类型 4）。

### A5 轴心受压构件整体稳定 `column_buckling`

| 专有槽位 | 单位 | 说明 / 依据槽位 |
|---|---|---|
| `section` | enum + 尺寸字典 | 双轴对称工字形 / H 型钢 / 箱形 / 圆管 / 角钢 / T 形等，提供 `A, I_x, I_y, i_x, i_y` 或可推导尺寸 |
| `section_class` | enum `a | b | c | d` | 截面分类：按原文章节/表判定（轧制/焊接、翼缘、板件宽厚比条件）；分类依据必须挂条号（§槽位：稳定截面分类） |
| `l_0x`, `l_0y` | mm | 平面内/外计算长度（计算长度系数若由支撑条件给定则输入 `k`×`l`） |
| `slenderness_check` | — | `λ = l_0/i`；容许长细比 `[λ]` 检查（查 T-slenderness-limit） |
| `phi` | float | 稳定系数：由 `section_class` + `λ`（或正则化长细比）查 T-buckling-curve；入库形态见决策 T2 |
| 判定项 | — | `N/(φ·A) ≤ f`；单面连接单角钢另有强度折减（扩展项，未核对即不启用） |

**易错点（写进生成器注释与自校验样例）**：
1. 等稳定性 vs 局部稳定两条路径混淆（本模块只做整体稳定，板件宽厚比属构造检查或扩展）；
2. φ 表按 λ 的插值口径（离散表 + 显式线性插值 vs 拟合公式）必须与来源一致，不得自行拟合；
3. λ 的取舍（较大者）与绕轴方向；
4. 换算长细比（虚轴）——格构式构件首期不做，接口预留。

## 四、文本核查规则表 schema 与首期规则清单

```json
// data/rules/description_rules.json 片段
{ "id": "R-WELD-CLASS-001", "name": "对接焊缝质量等级与受力匹配",
  "basis": [{"clause_id": "§待回填", "gist": "拉力垂直于焊缝方向时应为一/二级"}],
  "check_type": "consistency | limit | construct | presence | cross_param",
  "gate_keywords": ["对接焊缝", "焊缝质量", "一级", "二级"],
  "logic": {"require_any": ["weld_class"], "op": ">=", "value": "二级", "when": {"slot": "tension_perpendicular", "truth": true}},
  "level_rules": { "missing": "abnormal", "mismatch": "abnormal", "ambiguous": "suspicious" },
  "suggestion": "补写焊缝质量等级并明确对应检验要求",
  "status": "pending" }
```

首期规则清单（每条完成原文核对后才从 `pending` 升 `verified`，未核对规则**只能出 `suspicious`（待人工确认）不能出 `abnormal`**）：

| 组 | 规则（条数） | check_type | 门控关键词（类目隔离） |
|---|---|---|---|
| 材料 | 牌号/质量等级缺标注；牌号前后矛盾；Q235 用于焊接承重结构的适用性 | presence / consistency / limit | 钢材、牌号、Q235、Q355 |
| 焊接 | 焊缝质量等级选用；焊后处理与特殊要求（厚板、铸钢件、需预热焊后热处理的情形）；焊接材料与被焊构件匹配（E43/E50 系列与牌号对应） | limit / consistency | 焊缝、焊条、E43、E50 |
| 螺栓 | 性能等级与构件/受力匹配；摩擦面处理与抗滑移系数要求缺失；现场拼装高强螺栓终拧要求 | limit / presence | 螺栓、高强螺栓、摩擦面、抗滑移 |
| 构造 | 最小/最大焊脚、焊缝计算长度倍数、螺栓最小间距与边距越界（若说明写明） | construct | 焊脚、焊角、间距、边距 |
| 防护 | 防腐涂层体系与干膜厚度、防火时限与构件耐火等级匹配 | limit / presence | 涂装、防腐、防火、耐火 |

**三级判定语义（真值语义一次定清）**：`abnormal`（不符合，硬结论，须有 verified 依据）/ `suspicious`（可疑或需人工确认，含缺证据、歧义、多值）/ `pass`。评测按"文档全部非 pass 集合"与注入期望集对账；连带结论记入 `also_expect`，不计误报。

## 六、测试矩阵（M2～M4 交付）

| 层 | 测试 |
|---|---|
| schema | 条款/公式/表/规则/检查单 JSON 全部通过结构校验；引用完整性（formula→clause、table→clause 不得悬空） |
