## 一、统一计算契约

```python
Result = {
  "case_id": str,
  "module": "butt_weld | fillet_weld | bolt_normal | bolt_hsb_friction | column_buckling",
  "conclusion": "satisfied | unsatisfied | need_adjust | blocked",
  "ratio": float | None,            # 应力比 / 承载力比 = 作用效应 / 抗力设计值
  "steps": [                        # 计算过程透明：逐行可核
    {"no": 1, "formula_id": "F-…", "clause_id": "GB50017-2017:…",
     "expr": "h_e = 0.7*h_f", "substituted": {"h_f": 8.0}, "value": 5.6,
     "unit": "mm", "symbol_zh": "角焊缝有效厚度"}
  ],
  "basis": [{"clause_id": …, "title": …, "kind": …, "status": "verified"}],   # 去重依据清单
  "limits": [{"param": "min_h_f", "actual": 6.0, "bound": 5.0, "op": ">=", "clause_id": …, "ok": true}],
  "warnings": [{"type": "mandatory_clause", "clause_id": "…", "message": "强条核对提示"}],
  "blocked": [{"table_id": "T-…", "clause_id": "…", "reason": "status=pending，未挂原文核对"}],
  "meta": {"engine_version": …, "data_fingerprint": "sha256(data/clauses,data/tables)"}
}
```

- `conclusion` 判定：全部 `limits` 通过且 `ratio ≤ 1.0` → `satisfied`；`ratio > 1.0` → `unsatisfied`；`ratio ∈ (0.95, 1.0]` → `need_adjust`（提示接近限值，属"需调整/宜复核"而非硬判不符合）；任一必需数据 `status != verified`（即 `pending` 或 `located`）→ `blocked`（**不出数值**）。
- `data_fingerprint` 让"同输入必同输出"可被基准断言（数据变了指纹就变，回归差异可定位到数据层）。
- 容差：比值比较用相对容差 1e-3（内部计算）与真值比对的容差分开（真值容差按算例逐条登记，见 05 §四）。

**易错点（写进生成器注释与自校验样例）**：
1. 等稳定性 vs 局部稳定两条路径混淆（本模块只做整体稳定，板件宽厚比属构造检查或扩展）；
2. φ 表按 λ 的插值口径（离散表 + 显式线性插值 vs 拟合公式）必须与来源一致，不得自行拟合；
3. λ 的取舍（较大者）与绕轴方向；
4. 换算长细比（虚轴）——格构式构件首期不做，接口预留。

**判定闸门（本轮口径细化，替代原"pending 不得出 abnormal"单条）**：

| 依据 status | `consistency`（文档内部矛盾，不依赖规范数值） | `presence`（应有标注缺失） | `limit` / `construct`（依赖规范数值或限值形式） |
|---|---|---|---|
| `verified` | abnormal | abnormal | abnormal |
| `located`（仅条号+主题核对） | abnormal（证据=两处原文自相矛盾本身，无需规范数值） | **suspicious** | **suspicious**（数值未核对，不得硬判不符合） |
| `pending` | suspicious | suspicious | 规则不启用（不出结论） |

**关键：这条收紧不打挂检出率**——评测按"文档全部非 `pass` 集合"与注入期望集对账（K4），`suspicious` 同样计为检出；误报口径不变（非注入项被判非 pass 才算误报）。

**M3 落地时的两处形态收紧（06 D21，替代本文原稿的两处写法）**

1. 规则记录**不带 `level_rules` / `level_rules_if_verified` 字段**：等级由 `src/sdc/rules/gate.py` 的矩阵单点决定，有效档位取 `min(规则自身 status, 各依据条款 status)`。规则可以自称 verified，但只要依据只 located 就仍被压到 suspicious——把等级写进数据等于给规则发了绕过闸门的许可证。
2. `limit` / `construct` 规则在依据未核对时**阈值一律写 null**（`assert.min` / `assert.bound`），判定层记「规则不启用」并说明原因，**不是**降级成 suspicious：未核对的限值本就无从判起，每次都报“无法判定”只会把真实缺陷埋进噪声，并打挂 `误报 = 0` 的硬门（plan/05 §六）。

**三级判定语义（真值语义一次定清）**：`abnormal`（不符合，硬结论，须 verified 依据或文档内部矛盾证据）/ `suspicious`（可疑或需人工确认，含缺证据、歧义、多值、依据仅定位级）/ `pass`。连带结论记入 `also_expect`，不计误报。
