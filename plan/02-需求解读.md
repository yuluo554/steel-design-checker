## 一、痛点 → 能力转译

| # | 领域痛点（谁在什么场景卡住） | 转译成的产品能力 | 落地模块 |

## 二、功能需求清单（FR）

优先级：**P0 = 首期必须（DoD）**；P1 = 首期应有（时间不足可降级到"骨架+待核对"）；E = 扩展项（首期不做，接口预留）。

### FR-A 验算计算（核心）

| ID | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| FR-A1 | 对接焊缝强度验算（抗拉/抗压/抗剪，一、二、三级质量分级的取值差异） | P0 | 算例真值比对通过 |
| FR-A2 | 角焊缝强度验算（正面/侧面，h_e=0.7h_f 与 β_f；构造要求：h_f 最小/最大、l_w 最小与 h_f 倍数上限） | P0 | 同上 |
| FR-A3 | 普通螺栓验算（受剪/承压、受拉、剪拉联合；螺栓群剪力分配假定） | P0 | 同上 |
| FR-A4 | 高强度螺栓摩擦型验算（抗剪：μ、P、传力摩擦面数 n_f；抗拉；杆孔间隙与摩擦面处理状态取值） | P0 | 同上 |
| FR-A5 | 轴心受压构件整体稳定验算（λ=l_0/i、截面分类 a/b/c/d、φ 取值、φ 稳定判定） | P0 | 同上 |
| FR-A6 | 输入合法性校验：钢材牌号/厚度、焊缝等级、螺栓等级等枚举白名单；数值超范围即拒算并说明 | P0 | 单元测试（失败路径） |
| FR-A7 | 输出统一结构：应力比/限值比、结论（满足/不满足/需调整）、逐步计算轨迹、逐条依据 | P0 | 契约测试 |

## 三、边界与非目标（防 scope 失控）

- **输入面**：只做结构化参数卡 + 设计说明文本（docx/PDF 可抽取文本）。**不做**图像、扫描件 OCR、CAD/点云、BIM 模型读取——零识图路线。
- **计算面**：构件与连接级的单件验算。**不做**整体结构建模、有限元、荷载组合生成（设计内力作为输入给定）、节点域整体设计。
- **规范面**：GB 50017-2017 + GB 55006-2021（必要时引用 GB 55001-2021 的荷载与分项系数取值，入库时核对）。**不做**行业标准/地方标准/国外规范。
- **数据面**：只用教材/手册公开算例 + 自制合成说明。**不接**真实工程项目数据。
- **定性红线**：辅助验算工具，不替代正式设计文件与施工图审查；报告与界面强制免责声明。
- **条文纪律**：公式、强度设计值、φ 曲线、构造限值一律原文核对后入库（编号+条号+渠道+status）；查不到显式标"待核对"并**留在计算路径之外**。
- **形态纪律**：全离线、零 API 依赖、零 LLM 依赖（LLM 若引入只能作可选兜底且不得产生/修改任何判定，首期不引入）。

## 四、风险与对策

| ID | 风险 | 影响 | 对策 |
|---|---|---|---|
| R1 | 规范原文渠道不可达/被污染（JS 壳、摘要编造条号） | 条款库建不起来，P3 优势变空话 | 只用可直连原文页面逐字核对；要点+出处形式（不转载全文，规避版权）；两渠道全败 → 标 pending 继续推进，登记"待核验清单"（决策记录 D06） |
| R2 | φ 稳定系数是截面分类 + 长细比的函数，表格/公式两套来源易错 | 轴压模块真值不成立 | φ 数据来源唯一化（附录表 + 拟合公式二选一并在条款库说明取舍依据），交叉核对同值；拟合公式仅在原文给出系数时入库 |
| R3 | "教材算例"若凭记忆写数值，真值库自证循环 | 基准含金量崩塌 | 每个算例必须登记书名+版次+例题号；无法确证来源的数值**不得作为真值**，改列为"引擎自校验样例"（单位/单调性/极限情形），与真值库分目录分开统计 |
| R4 | 文本核查误报率目标 0，但说明文体例多样 | 误报毁掉可信度 | 规则只在明确模式匹配时下结论；任何缺证据/歧义 → `review` 级；合成语料覆盖变体，误报作为硬门槛指标 |
| R5 | Windows + Python 3.8 + PySide6 版本上限、PyInstaller 对新版 Python 的解析 bug | 打包卡死在最后一步 | 装前 spike 实测可解析最高版本并锁定；onedir 双 exe；构建通道与解释器版本如实入决策记录（M5 前置 spike） |
| R6 | 待核对条款长期悬空 → 首期只交付 2 个模块 | 交付面缩水 | 按模块推进门控：先做数据可核对性最高的模块（焊缝/螺栓），轴压 φ 表若 pending 则界面显示"数据待核对"而非硬算；里程碑 DoD 允许模块数下调但不得下调纪律 |
